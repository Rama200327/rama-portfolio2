# Rama Abuaqoulah — Portfolio

Personal portfolio of **Rama Abuaqoulah**, a .NET Full Stack Developer based in Amman, Jordan.

It presents my projects, work experience, skills and a downloadable CV.

## Built with

- React + TypeScript
- TanStack Start (file-based routing, static prerendering)
- Tailwind CSS
- GitHub Actions + GitHub Pages for deployment

## Run locally

```sh
bun install
bun run dev
```
